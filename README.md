# Nova-Assistant-
Nova is an intelligentbassistant designed to perform a wide range of tasks, from providing information to executing system commands. Nova interacts with users via voice commands, making it highly user-friendly and accessible for day-to-day operations.

# System Requirements
- **Operating System:** Windows, macOS, or Linux
- **Python Version:** Python 3.8 or above
- **Dependencies:**
  - `pyttsx3`
  - `speech_recognition`
  - `requests`
  - `wikipedia`
  - `webbrowser`
  - `pywhatkit`
  - `pyjokes`
  - `pyautogui`
  - `BeautifulSoup` (for web scraping)

# What Operations Can Nova Perform?

1. **Voice Recognition:** Accepts and processes voice commands.
2. **Text-to-Speech:** Communicates responses verbally.
3. **Web Searches:** Opens web pages and searches for information on Google or Wikipedia.
4. **News Updates:** Fetches the latest headlines from predefined sources.
5. **Stock Prices:** Provides real-time stock prices, including Nifty Fifty and other shares.
6. **Calculations:** Performs basic arithmetic operations and evaluates expressions.
7. **File Management:** Opens applications such as Notepad and Command Prompt.
8. **Location Detection:** Identifies the user's geographical location via IP address.
9. **Screenshot Capture:** Takes and saves screenshots with user-defined names.
10. **Humor:** Tells jokes using the `pyjokes` library.

# Modules Used

- **`pyttsx3`:** Text-to-speech conversion.
- **`speech_recognition`:** Captures and processes user voice commands.
- **`datetime`:** Provides current date and time information.
- **`os`:** Manages file operations.
- **`wikipedia`:** Fetches information from Wikipedia.
- **`webbrowser`:** Opens web pages in the default browser.
- **`pywhatkit`:** Handles YouTube and Google searches.
- **`smtplib`:** Sends emails (not yet implemented in the provided code).
- **`requests`:** Fetches data from the internet, such as news and IP address information.
- **`pyjokes`:** Generates jokes.
- **`pyautogui`:** Captures screenshots.
- **`BeautifulSoup`:** Parses and scrapes HTML content from websites.
